## 1. 管理后台

### 启动

```bash
pnpm dev:api
open http://127.0.0.1:4100
```

页面会要求输入 `ADMIN_TOKEN`（来自 `.env`）。

### 页面

- 概览：用户数、今日消息、今日运行、今日 tokens、待发提醒、知识库文档
- 用户：wx id、消息/运行数、今日 tokens、最后活跃
- 运行：状态、模型、tokens、耗时、错误
- 近 7 天用量
- 提醒状态
- 知识库文档

> 当前是零构建的静态 HTML 仪表盘，不是 React；M4b 再换 React 或保留。

### API

所有 `/api/v1/*` 需要 header：

```http
x-admin-token: <ADMIN_TOKEN>
```

| 方法 | 路径 | 内容 |
|---|---|---|
| GET | `/api/v1/overview` | 概览 |
| GET | `/api/v1/users?limit=50` | 用户列表 |
| GET | `/api/v1/users/:id/messages` | 用户消息 |
| GET | `/api/v1/runs?limit=50` | 运行记录 |
| GET | `/api/v1/reminders?limit=50` | 提醒 |
| GET | `/api/v1/knowledge` | 知识库文档 |
| GET | `/api/v1/usage` | 近 7 天用量 |
| GET | `/healthz` | 健康检查 |

默认只监听 `127.0.0.1:4100`（`API_HOST` 可改）。生产放 Caddy 后应加 IP allowlist。

## 2. 每日预算

配置：

```dotenv
MAX_DAILY_TOKENS=100000
```

- 每次回答前，按 `runs` 汇总该用户当天（Asia/Shanghai）tokens；
- 达到上限：不调 LLM，直接回复“今天的 AI 额度已用完…”，run 标记 `DAILY_BUDGET_EXCEEDED`；
- `/help`、`/whoami`、`/reset`、`/remind` 不消耗 API；
- 概览页显示今日 tokens，方便观察。

限制：

- 按 token 不按金额；
- 没有按用户单独配置额度（全局默认）；
- 没有告警；M4b 加。

---

## 3. 安全

- `ADMIN_TOKEN` 只放 `.env`，不要提交。
- 后台默认 localhost；公网暴露必须加 TLS + IP allowlist。
- 前端 token 存 `localStorage`，适合本机运营，不适合多用户后台。
- 没有 RBAC/审计登录；M4b 再做。
