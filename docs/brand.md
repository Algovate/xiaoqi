## 2. 为什么是“小栖”

### 2.1 从“群栖”收缩到“小栖”

Phase 0 证明：扫码 iLink bot 无法加入普通微信群，群助手方案不可行。  
“群栖”这个名字会把用户预期带到“群”，所以 v1 收缩为：

> **小栖**：微信里只属于你的 AI 助理。

“栖”保留下来——它是“落脚、安放”的意思；去掉“群”，从一群人的栖息地，变成你自己的一个小位置。

### 2.2 品牌故事

微信里总有一个对话框，是你自己的。  
你把问题、截图、PDF、待办丢进去，小栖接住，记住上下文，给出结论。

不抢话，不刷屏；你叫它，它就在。

### 2.3 语义层次

| 层次 | 含义 |
|---|---|
| 字面 | 小栖：一个小小的落脚处 |
| 产品 | 私聊里的 AI 助理：问答、看文件、记忆、提醒 |
| 情绪 | 安静、可靠、随时在；不是客服，也不是玩具 |
| 扩展 | 小栖·知识库、小栖·提醒、小栖·周报 |

### 2.4 为什么不是其他名字

| 候选 | 问题 |
|---|---|
| 群栖 / Qunqi | 群聊 No-Go，名字误导 |
| 群犀 / 群青 / 群脉 | 有同名或近似品牌；仍带“群” |
| 栖言 / 栖记 | 更文艺，但辨识度和口语感弱于“小栖” |
| Perch / Roost | 英文已有同名 AI/软件产品 |

> 正式启用前仍需做第 9/42 类商标、域名、公众号/小程序名检索。

## 3. 品牌语气

- 像微信里一个靠谱的朋友，不像客服，也不像玩具。
- 先结论，后依据；不确定就说“没查到/资料里没有”。
- 不卖萌、不刷屏、不伪造“已完成”。
- 称呼自己“小栖”，不称呼“本 AI/本助手”。
- 失败时给 trace，不暴露堆栈。

示例：

```text
你：帮我总结这份 PDF，重点看付款条款
小栖：已看完。3 个关键点：
• 付款账期 30 天，逾期按 0.05%/日
• 首付款 30%，验收后 70%
• 争议解决地：深圳
需要我把风险条款单独列出来吗？
```

## 4. 视觉方向

- **主色**：墨绿 `#1F3D33` + 米白 `#F6F2E9`，点缀微信绿 `#07C160`。
- **辅助色**：暖灰、深墨；不用蓝紫赛博渐变。
- **图形**：一只停在对话气泡上的小鸟 / 一根树枝 + 气泡；负空间做“栖”字。
- **字标**：中文“小栖”用宋体/思源宋体，英文“XIAOQI”用无衬线大写。
- **动效**：小鸟落下、气泡展开；克制，不弹跳。
- **禁忌**：机器人头像、脑图、齿轮、紫色光晕；不要过度可爱化。
