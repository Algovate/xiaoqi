# M1 · 私聊链路骨架

> 日期：2026-11-06  
> 状态：已验收（fake iLink + 真实微信私聊 echo）  
> 目标：登录 → 长轮询 → 私聊落库 → outbox → worker echo → 发送

---

## 1. 范围

### 已实现

- TypeScript monorepo（pnpm workspace）
- `packages/core`：配置、日志、错误、AES-GCM token 加密、Drizzle schema、SQL migration
- `packages/ilink`：iLink 客户端、登录、长轮询、发送、bigint 保留解析
- `apps/gateway`：登录 CLI、leader 锁、poll loop、入站事务、内部发送 API
- `apps/worker`：outbox dispatcher、BullMQ、DM echo
- `poc/fake-ilink.mjs`：离线端到端测试
- `docker-compose.yml`：本地 Postgres + Redis

### 未实现（M2+）

- LLM 回答（当前是 `收到：...` echo）
- 图片/PDF 解析与媒体出站
- 摘要、提醒、知识库
- 管理后台
- 完整限流/预算/可观测

## 2. 数据流

```text
微信/iLink
  → gateway getupdates
  → messages + account_cursors + outbox（同事务）
  → outbox dispatcher
  → BullMQ dm.message
  → worker 创建 run
  → gateway /internal/v1/send
  → iLink sendmessage
  → outbound_messages sent
```

关键点：

- 游标只在事务提交后推进；
- `message_id` 用字符串保留（getupdates 里是超出 JS 安全整数的 JSON number）；
- `context_token` AES-GCM 加密存 `context_tokens`；
- 发送幂等键：`(run_id, chunk_index)`。

## 3. 本地启动

### 3.1 依赖

```bash
docker compose up -d postgres redis
pnpm install
```

### 3.2 环境变量

```bash
cp .env.example .env
openssl rand -base64 32   # 填入 MASTER_KEY
openssl rand -hex 24      # 填入 INTERNAL_TOKEN
```

`.env` 至少：

```dotenv
DATABASE_URL=postgres://xiaoqi:xiaoqi@127.0.0.1:5432/xiaoqi
REDIS_URL=redis://127.0.0.1:6379
MASTER_KEY=base64:...
INTERNAL_TOKEN=...
GATEWAY_INTERNAL_URL=http://127.0.0.1:4101
```

### 3.3 迁移

```bash
pnpm db:migrate
```

### 3.4 登录

```bash
pnpm ilink:login
```

扫码确认后，token 加密写入 `accounts`。

### 3.5 启动

```bash
pnpm dev:gateway   # 4101
pnpm dev:worker    # 4102 health
```

在微信里私聊 bot，应收到：

```text
收到：<你发的文本>
```

## 4. 离线验证（不用微信）

```bash
# 终端 A
node poc/fake-ilink.mjs

# 终端 B
ILINK_BASE_URL=http://127.0.0.1:8787 pnpm ilink:login
ILINK_BASE_URL=http://127.0.0.1:8787 pnpm dev:gateway

# 终端 C
pnpm dev:worker
```

fake 会返回一条私聊消息；worker 会 echo 到 fake 的 `sendmessage`。

检查：

```sql
select id, conversation_key, text from messages;
select id, status, trigger_message_id from runs;
select run_id, chunk_index, status, wx_message_id from outbound_messages;
select id, status from outbox;
```

## 6. 已知限制

- 只处理私聊；`group_id` 非空的消息会跳过并计数。
- 只做文本 echo；图片/文件只记录，不解析。
- 没有 LLM、没有分段、没有 typing。
- 没有重试 UI；失败看日志/DB。
- gateway 的 leader 锁是单账号粒度；多实例可扩展，但 M1 单实例。
- `notifystart/stop` 失败只 warning（部分服务端可能不支持）。
- 管理 API/后台尚未开始。
