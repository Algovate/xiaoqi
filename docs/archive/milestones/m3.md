# M3 · 文件理解 + 对话摘要 + 命令

> 日期：2026-11-06  
> 状态：已实现（PDF/DOCX/TXT 抽取、DeepSeek 视觉、macOS OCR、`/summary`、`/reset`）  
> 目标：让私聊助理能“看文件、总结对话、清上下文”

---

## 1. 已实现

### 1.1 文件/PDF

- 下载 iLink 媒体 → AES-128-ECB 解密
- 支持：
  - PDF：`unpdf` 提取文本（≤200 页）
  - DOCX：`mammoth` 提取文本
  - TXT/MD：直接读文本
  - 图片：下载/解密 → **DeepSeek Flash 视觉模型**描述内容；失败回退 **macOS Apple Vision OCR**
- 媒体落盘到 `MEDIA_DIR/<accountId>/<messageId>-<index>.<ext>`
- 视觉模型：DeepSeek `deepseek-flash`（支持 image input）
- OCR：macOS 本地 Apple Vision，`tools/ocr-bin`；作为视觉模型失败时的兜底
- 构建：`pnpm ocr:build`（需要 Swift，macOS）
- 提取文本写入 `media_assets.extracted_text`，随当前问题注入上下文
- 上限：20MB / 20k 字符

### 1.2 命令

| 命令 | 行为 |
|---|---|
| `/help` | 用法卡片 |
| `/summary` | 总结最近 80 条对话，并写入 `conversation_state.summary` |
| `/reset` | 设置 `reset_at`，清空摘要；后续上下文只从 reset 之后取 |
| `/whoami` | 返回用户 ID |

### 1.3 上下文

- `conversation_state.summary` 注入 `<summary>`
- `reset_at` 过滤旧消息
- 附件文本注入 `<attachments>`
- 结构：

```text
<summary>...</summary>
<conversation>[14:02] 你：...</conversation>
<attachments>[文件：a.pdf]...</attachments>
<current_question>...</current_question>
```

## 4. 现在怎么用

重启 gateway/worker（tsx watch 会自动重载），然后私聊：

```text
/help
/summary
/reset
```

发一个 PDF + 问题：

```text
[PDF] 帮我总结付款条款
```

小栖会抽取 PDF 文本后回答；图片会先走 DeepSeek Flash 视觉描述；失败再走本地 OCR。

## 5. 已知限制

- 视觉模型可能对模糊图片/复杂图表产生误读；提示词要求“看不清就说看不清”。
- OCR 作为兜底，质量受截图清晰度影响。
- Linux 部署时视觉模型仍可用（走 API）；本地 OCR 需要关闭或换 tesseract/云 OCR。
- 扫描 PDF 会回退到 OCR（前 10 页，macOS）；没有 OCR 时提示“可能是扫描件”。
- **知识库未做**：附件只在当前轮使用，没有持久 RAG。
- **提醒未做**：`/remind` 还在 M3b。
- **视觉成本**：每张图片会消耗约 1k prompt tokens；预算控制未做。
- **预算未做**：没有按用户日预算降级。
- **摘要存储简单**：`/summary` 覆盖写，没有滚动摘要任务。
