# M5 · Codex 任务 Runner

> 日期：2026-11-06  
> 状态：已实现（Codex + DSH runner、resume、diff、Admin 任务页）  
> 目标：在微信里把 Codex 任务丢进允许的 repo，跟踪状态，完成后通知

---

## 1. 能做什么

```text
/codex xiaoqi 修复失败的测试
/codex resume <任务ID前8位> 继续补测试
/dsh xiaoqi 分析仓库
/dsh list
/codex status <任务ID前8位>
/codex stop <任务ID前8位>
```

- `/codex <repo别名> <任务>`：Codex 入队
- `/codex resume <id> <追加指令>`：用上次 Codex session 继续
- `/dsh <repo别名> <任务>`：DSH 入队
- Runner 串行执行 `codex exec --json` / `codex exec resume` / `dsh headless`
- 完成后计算 `git diff --stat` + `git status --short`，附在通知里
- Admin 后台任务表含 engine/类型/变更

## 2. 配置

`.env`：

```dotenv
CODEX_BIN=codex
DSH_BIN=dsh
CODEX_REPOS=xiaoqi=/Users/rodin/Workspace/algovate/ilinkai
CODEX_ALLOWED_USERS=o9cq...@im.wechat
CODEX_TIMEOUT_MS=900000
DSH_TIMEOUT_MS=900000
```

- `CODEX_REPOS`：`别名=绝对路径`，逗号分隔；**不在 allowlist 的路径不可用**
- `CODEX_ALLOWED_USERS`：允许触发 Codex 的微信用户 ID
- `CODEX_TIMEOUT_MS`：默认 15 分钟

---

## 3. 启动

```bash
pnpm dev:runner
```

DSH 需要 `headless` profile 可用；如果 `dsh headless` 报 profile 不存在，先在普通终端跑一次 `dsh headless --help` 让它初始化。

Runner 与 gateway/worker 分开：

```text
worker   → 处理 /codex 命令，写 codex_tasks
runner   → 串行执行 codex exec
gateway  → 发送完成通知
```

> 重要：Runner 最好在**普通终端**运行，不要在 DSH 的 app sandbox 里跑；Codex CLI 需要写 `~/.codex`，沙箱可能报 `EPERM`。

---

## 4. 执行细节

```text
codex exec --json
  -C <allowlisted repo>
  --sandbox workspace-write
  -o <temp file>
  <prompt>

# DSH
dsh headless "<prompt>"   # cwd = repo
```

- 进程组启动，超时/停止时 `kill(-pid)`
- 解析 stdout JSONL：
  - 记录 `last_event`
  - 抽取 `session_id`
  - 事件写入 `codex_task_events`
- 退出后读 `-o` 文件作为最终摘要
- 退出后计算 `git diff --stat` + `git status --short` 存入 `diff_stat`
- DSH 没有 JSONL/session，stdout 直接作为摘要
- 状态：`queued → running → completed | failed | cancelled`
- 通知格式：

```text
✅ Codex 任务 abcd1234 完成
仓库：xiaoqi

<最终摘要>
```

## 7. 安全边界

- 只允许 `CODEX_REPOS` 中的绝对路径
- 只允许 `CODEX_ALLOWED_USERS` 中的微信 ID
- 固定 `--sandbox workspace-write`
- 不使用 `--dangerously-bypass-approvals-and-sandbox`
- 单 runner 串行，超时杀进程组
- 任务 prompt 由用户提供，但 Codex 只能在指定 repo 内工作
- 建议用独立系统用户/容器运行 runner

---

## 8. 已知限制

- 单任务串行，没有按 repo 并行；
- 不支持 `codex exec resume`（下一步）；
- diff 只是 `--stat` + `status`，没有逐行 review；
- DSH 只有一次性 `headless`，没有 session/resume；
- DSH 输出是纯文本，事件粒度比 Codex 粗；
- Codex/DSH 权限/沙箱依你的本机配置，失败会写 `error`；
- 完成通知依赖用户最近 context_token，过期会失败但任务仍完成。
